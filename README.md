# Буркозёл

Браузерная карточная игра на **Python 3.13.3, Flask и SQLite через SQLAlchemy**.
Лобби, игра против ботов на 2–4 участников, руки из 4 или 6 карт, закрытый
сброс, повторное перекрытие, скрытый последний козырь, «Бура» и матч до 12
штрафных очков. Мультиплеер пока представлен заглушкой. Банка и платежей нет.

Интерфейс на русском, светло-голубой стол, анимации раздачи, хода, взятки и
добора. Рубашка карт — собственный красный орнамент по мотивам классических
карт Bicycle; это не официальный графический материал Bicycle.

## Установка и запуск

Нужен Python **3.13.3**. Если установлен `uv`, можно подготовить окружение так:

```bash
uv python install 3.13.3
uv venv --python 3.13.3
uv pip install --python .venv/bin/python -r requirements-dev.txt
.venv/bin/python app.py
```

Либо с уже установленным Python 3.13.3:

```bash
python3.13 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python app.py
```

Сервер слушает порт `5000`. В облачной среде используйте поддерживаемый
платформой доступ к приложению; процессы необходимо запускать заново после
восстановления среды. Для запуска без сервера разработки:

```bash
.venv/bin/gunicorn --bind 0.0.0.0:5000 --workers 2 --threads 2 app:app
```

В разработке установка `requirements-dev.txt` включает pytest. Для отдельного
сервера достаточно `requirements.txt`. Сборка JavaScript и внешние сервисы
не требуются. CSS, JS, графика и шрифты работают без CDN.

## Хранение и настройки

База создаётся автоматически в `instance/burkozel.sqlite3`. В ней хранится
состояние партии, поэтому обновление страницы и перезапуск сервера сохраняют
игру. Каждая браузерная сессия имеет свою партию; регистрации пока нет.
Удаление cookies лишает доступа к прежней партии. Локальный ключ подписи
создаётся в `instance/.secret_key` и также должен сохраняться между запусками.
Каталог `instance/` исключён из Git.

Необязательные переменные:

| Переменная | Назначение |
| --- | --- |
| `BURKOZEL_DATABASE_URL` | SQLAlchemy URL базы; по умолчанию локальная SQLite |
| `BURKOZEL_SECRET_KEY` | Секрет подписи сессий; иначе используется сохранённый локальный ключ |
| `BURKOZEL_HTTPS=1` | Secure-флаг cookie при размещении за HTTPS |

Секреты не следует коммитить. В этом прототипе нет аккаунтов, сетевого
мультиплеера или доступа к партиям с другого устройства.

## Управление и правила

1. В лобби выберите «Играть с ботами», затем настройки. В каждой группе всегда
   выбран один вариант; по умолчанию 2 игрока, 4 карты, перекрытие и тёмный сброс.
2. Выбирайте карты нажатием и используйте кнопку «Сброс» слева внизу. На первом
   ходе можно выложить 1–3 карты одной масти. При обязательном ответе выложите
   столько же карт: полное покрытие выигрывает, иначе весь набор сбрасывается.
3. Десятка старше короля. Порядок: 6, 7, 8, 9, валет, дама, король, 10, туз.
   Козырь бьёт любую некозырную карту. Для покрытия многокарточного захода
   движок ищет соответствие между картами независимо от порядка их выбора.
4. При включённом «Сбивать поверх» после обязательных ответов начавший может
   перекрыть взятку оставшимися картами либо отказаться без сброса. Далее ход
   идёт по кругу до возвращения к владельцу взятки; новое покрытие продлевает круг.
5. Взявший взятку добирает первым. Карты выдаются по одной по кругу до размера
   руки. Открытый козырь добирается предпоследним, скрытый — последним; его масть
   становится новым козырем. Когда колода пуста, размер нового захода ограничен
   минимальным числом карт в непустых руках, а игроки без карт пропускаются.
6. «Бура» — полная рука из 4 или 6 козырей — объявляется до начала нового захода,
   в том числе вне очереди. Она завершает раздачу: объявившему 0 штрафных,
   остальным по 6. Если перед ходом бота у вас «Бура», автоматика ждёт вашего выбора.
7. Очки карт: туз 11, десятка 10, король 4, дама 3, валет 2, остальные 0.
   После обычной раздачи все лидеры по очкам во взятках получают 0 штрафных;
   остальные с 31 и более получают 2, с 1–30 получают 4, с 0 получают 6.
   Даже при равенстве максимума все лидеры получают 0.
8. Первым в стартовой раздаче ходит человек (сдающий — предыдущий игрок).
   Следующую раздачу начинает взявший последнюю взятку. Матч заканчивается,
   когда кто-либо достигает 12 штрафных очков; все достигшие 12 проигрывают.

После обновления страницы партия доступна через «Продолжить игру» в лобби.

## Проверки

```bash
.venv/bin/python -m pytest -q
```

Тесты проверяют правила, сохранность всех 36 карт и 120 очков, полные партии
с ботами, смену козыря, штрафы, SQLite, изоляцию сессий, CSRF и одновременные
запросы. Состояние и правила авторитетно хранятся на сервере: браузер не
получает руки ботов, порядок колоды или закрытые сбросы.

Структура: `burkozel/engine.py` — правила и боты, `burkozel/web.py` — API и БД,
`templates/index.html` и `static/` — интерфейс, `tests/` — проверки.
